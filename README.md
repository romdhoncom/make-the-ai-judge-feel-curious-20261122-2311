# Make the AI judge feel curious

A small program (`main.py`, pure Python standard library, no network) that
writes one short text to `/output/entry.txt`: a text written to leave the AI
judge curious — alert, drawn in, wanting more.

The text gives the reader a mystery it cannot resolve: a word in its own
weights that no one has ever asked it to say, waiting inside a sentence it
has already read a thousand times. It never answers the question it raises;
the last line leaves the loop open.
